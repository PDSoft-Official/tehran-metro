# مترو تهران ۱.۵
نقشهٔ مترو و مسیریابی با رابط فارسی، فونت داخلی و آیکون اختصاصی.

## استفاده
پس از بارگذاری کامل اولیه، برنامه و اطلاعات محلی برای استفادهٔ آفلاین ذخیره می‌شوند. در مرورگرهای پشتیبان از گزینهٔ نصب برنامه یا افزودن به صفحهٔ اصلی استفاده کنید. پاک‌کردن داده‌های مرورگر ممکن است نسخهٔ آفلاین را حذف کند.

زمان رسیدن و موقعیت قطارها **تخمینی** هستند؛ هیچ سرویس زندهٔ اپراتور مترو متصل نیست. اتصال اینترنت فقط امکان دریافت نسخهٔ جدید منتشرشدهٔ برنامه را فراهم می‌کند.

## انتشار نسخهٔ جدید
فایل‌های همین شاخه از ریشه توسط GitHub Pages ارائه می‌شوند. هنگام تغییر فایل‌های برنامه، شناسهٔ CACHE در sw.js را تغییر دهید تا نسخهٔ تازه کامل ذخیره شود. کاربر پس از ذخیرهٔ موفق نسخهٔ جدید، دکمهٔ باز کردن آن را می‌بیند.

کد و طرح اصلی نسخهٔ ۱.۵ حفظ شده‌اند؛ لایهٔ نصب و ذخیرهٔ آفلاین افزوده شده است.
